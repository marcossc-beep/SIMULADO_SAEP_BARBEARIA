// ### bcrypt: HASH de via única

- Criptografia tradicional: vai e volta (criptografa e descriptografa com uma chave).
- Hash (bcrypt): só vai. Depois de virar hash NÃO dá para voltar ao texto original.
- Salt: texto aleatório misturado antes do hash. Dois "123" geram hashes diferentes.
- O 10 em bcrypt.hash(texto, 10) é o custo (quantas rodadas). 10 é o padrão.

import bcrypt from 'bcrypt'

// Cadastro: gerar o hash
const senhaHash = await bcrypt.hash(body.senha, 10)
const cpfHash = await bcrypt.hash(body.cpf, 10)

// Login: comparar o que foi digitado com o hash do banco (true ou false)
const senhaValida = await bcrypt.compare(body.senha, usuario.senha)

Como fica no banco:
  cpf   = $2b$10$Q3x9...   (60 caracteres - por isso a coluna é VARCHAR(255))

Consequência: o CPF NÃO aparece na listagem e, na edição, o usuário só digita
CPF/senha se quiser trocar. É assim mesmo, o dado está protegido.

// ### JWT (JSON Web Token): o "crachá" do usuário

Depois do login a API gera um token e o front guarda. Em toda requisição o
front mostra o crachá (header Authorization). O crachá tem VALIDADE.

Estrutura: header.payload.signature
- header: algoritmo
- payload: dados do usuário (id, nome, email) + exp (quando expira). NUNCA a senha.
- signature: assinatura que garante que ninguém alterou o token.

import jwt from '@fastify/jwt'

servidor.register(jwt, {
    secret: 'saep_barbearia_2026',     // chave que assina o token
    sign: { expiresIn: '30m' }         // TEMPO DE EXPIRAÇÃO da sessão
})

// OBS: na prova a chave fica direto no código (sem .env), não é critério avaliado.
// Em um sistema real ela ficaria em variável de ambiente.

// Gerar o token no login
const token = servidor.jwt.sign({ id: usuario.id, nome: usuario.nome, email: usuario.email })

// Descobrir quando expira (exp vem em segundos, o JavaScript usa milissegundos)
const expira = servidor.jwt.decode(token).exp * 1000

// Verificar o token em uma rota protegida
await request.jwtVerify()    // se expirou ou é inválido, lança erro


// ### Rota de login completa

servidor.post('/login', async (request, reply) => {
    const body = request.body

    if (!body || !body.email || !body.senha) {
        return reply.status(400).send({ message: 'E-mail e senha são obrigatórios!' })
    }

    const resultado = await sql.query('SELECT * FROM usuario WHERE email = $1', [body.email])

    if (resultado.rows.length === 0) {
        return reply.status(401).send({ message: 'Usuário ou senha inválidos!' })
    }

    const usuario = resultado.rows[0]
    const senhaValida = await bcrypt.compare(body.senha, usuario.senha)

    if (!senhaValida) {
        return reply.status(401).send({ message: 'Usuário ou senha inválidos!' })
    }

    const token = servidor.jwt.sign({ id: usuario.id, nome: usuario.nome, email: usuario.email })
    const expira = servidor.jwt.decode(token).exp * 1000

    return reply.status(200).send({
        message: 'Login realizado com sucesso!',
        token: token,
        expira: expira,
        usuario: { id: usuario.id, nome: usuario.nome, email: usuario.email }
    })
})

// Dica de segurança: a mensagem é a MESMA para e-mail errado e senha errada,
// assim ninguém descobre quais e-mails existem no sistema.
